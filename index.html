FEATURES

Everything you need to start

01

GitHub Actions ready

A complete .github/workflows/ci.yml included. Works out of the box on any GitHub repo.

02

Automated tests

A sample test suite using plain JS. Add your own tests and they'll run automatically on every push.

03

Lint configured

ESLint is set up with sensible defaults. Code quality is checked before anything else runs.

04

Environment separation

Deploy only on main branch pushes. PRs run lint and tests only — no accidental deploys.

05

Clean project structure

Organised src/ folder, separate CSS and JS, and a tests/ directory from day one.

06

Beginner friendly

Every file is commented. Built to learn from — understand CI/CD by reading real working code.
